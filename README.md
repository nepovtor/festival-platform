# «Город говорит» — платформа городского фестиваля

Полнофункциональный адаптивный сайт фестиваля: публичный лендинг, программа,
галерея, предварительная регистрация, подтверждение по email и защищённая
панель организатора.

## Возможности

- адаптивный одностраничный лендинг от 320 px;
- навигация с плавной прокруткой;
- программа фестиваля из отдельного типизированного файла;
- оптимизированная адаптивная галерея;
- единая Zod-схема клиентской и серверной валидации;
- нормализация email и запрет повторной регистрации;
- ограничение частоты запросов — 5 за 10 минут;
- honeypot-поле и ограничение размера тела запроса;
- постоянное хранение регистраций в локальном JSON-файле;
- письмо-подтверждение через Resend;
- регистрация сохраняется даже при ошибке почтового сервиса;
- защищённая страница `/admin/registrations`;
- статистика, поиск по email и CSV-экспорт;
- SEO-метаданные, sitemap, robots и запрет индексации админки;
- доступные состояния формы и поддержка `prefers-reduced-motion`.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Приложение будет доступно на `http://localhost:3000`. Данные сохраняются в
`data/registrations.json`; путь можно изменить через `FESTIVAL_DATA_FILE`.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

```env
RESEND_API_KEY=
EMAIL_FROM=Festival <festival@example.com>
EMAIL_REPLY_TO=hello@example.com
NEXT_PUBLIC_SITE_URL=http://localhost:3000
ADMIN_USERNAME=organizer
ADMIN_PASSWORD=change-this-to-a-long-unique-password
FESTIVAL_DATA_FILE=./data/registrations.json
```

Без параметров Resend регистрация сохраняется, а статус письма отмечается как
`FAILED`. После добавления ключа подтверждения отправляются автоматически.

## Запуск в Docker

Скопируйте `.env.example` в `.env`, обязательно задайте сложный
`ADMIN_PASSWORD`, затем запустите:

```bash
docker compose up --build
```

Сайт откроется на `http://localhost:3000`. Административная страница и
CSV-экспорт используют HTTP Basic Auth с логином и паролем из `.env`. Данные
регистраций сохраняются в Docker volume `festival-data`.

## API

`POST /api/registrations`

```json
{
  "email": "user@example.com",
  "guestsCount": 3,
  "consent": true,
  "website": ""
}
```

Ответы: `201` — регистрация создана, `400` — ошибка валидации, `409` — email
уже зарегистрирован, `429` — превышен лимит, `500` — внутренняя ошибка.

## Подготовка к реальному событию

Перед публичным запуском замените демонстрационные название, адрес, контакты,
программу и текст политики в `content/` и `app/privacy/`, добавьте ключ Resend и
проверьте адрес отправителя. Перед запуском задайте сложный пароль для
административной страницы и храните файл `.env` вне репозитория.
